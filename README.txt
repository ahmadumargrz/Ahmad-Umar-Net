NETWATCH - NETWORK MONITORING APP

Files:
- index.html: application structure
- style.css: black and white responsive design
- script.js: app functionality

HOW TO RUN:
1. Extract this ZIP file.
2. Keep all three code files in the same folder.
3. Open index.html in a modern browser.
4. An internet connection is required for the Cloudflare-based speed test.

NOTES:
- Browser APIs generally do not expose actual cellular signal strength or operator coverage.
- Network comparison and coverage entries are manually submitted measurements/reports.
- Data is stored in browser localStorage on this device only.
- Community reports are not shared with other users without a backend/database.
